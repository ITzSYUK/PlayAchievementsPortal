# Проба стабильности LocoRoco 0.3-lite

Результат 14 октября: владелец подтвердил хорошую работу игры, все 121 замер
и нормальное завершение пробы. В основном user-разделе свободный запас
уменьшался до 569600 байт (556,25 КиБ). Следующий шаг —
[запрос карты дополнительных разделов](INGAME_MEMORY_LAYOUT.md), без выделения памяти.

На PSP-3000, 6.60 + ARK5 включённая полная проба 0.2 приводит к выключению
после вступительного ролика. С отключённой пробой владелец пропустил ролик,
начал игру и подтвердил нормальную работу. Точную причину сбоя ещё не установили.
Версию 0.2 не используй для новых тестов.

В её логах подтверждены загрузка worker, успешная регистрация user power
callback, совпадение исходных байтов disc0 с официальным RA-хешем ISO:
`199515744d49ef3620a5f9297c6116f9`. HTTPS не запускался (`TLS=0/0`).
Последние два замера наблюдателя записаны примерно через 1 и 2 секунды.
Нормального завершения в логах нет; это не exception trace и не доказательство OOM.

## Что проверяет новый пакет

0.3-lite содержит только отдельный kernel PRX `RAInGameLite`. Один поток
с приоритетом 0x60 и стеком 8 КиБ ждёт имя модуля LocoRoco, затем раз в секунду
записывает свободную память user partition 2 и размер её крупнейшего свободного
блока. Продолжительность — 120 интервалов; файловые вызовы могут её увеличить.
Запросы выполняются через API памяти SDK, память игры не разыменовывается.

Здесь отсутствуют worker, newlib heap, user control block, TLS/сеть, power
callback, чтение disc0, pad/display-вызовы и hooks. Нужен только этот PRX,
Wi-Fi и profile.txt для теста не нужны. Один обычный запуск 0.3 на PSP владельца
прошёл; sleep/resume и другие игры ещё не проверены.

Если она работает, следующий шаг — возвращать функции по одной после замера
доступной памяти. Нельзя объявлять нехватку памяти причиной только по тому,
что облегчённая проба работает. Полная 0.2 резервировала heap 2 МиБ плюс
модуль и стек worker, но её расход и требуемая память игры ещё не измерены.

## Установка и один запуск

1. Сохрани старые `RAInGameProbe/bootstrap.log` и `worker.log`.
2. Оставь запись `RAInGameProbe` в `PLUGINS.TXT` выключенной (`off`).
3. Распакуй `PSP_RA_InGameLite_v0.3.zip` в корень карты. Новый файл:
   `SEPLUGINS/RAInGameLite/RAInGameLite.prx`. Старые файлы не заменяются.
4. Добавь в используемый ARK список `ms0:/SEPLUGINS/PLUGINS.TXT` ровно одну
   строку (не заменяй список целиком):

   ```text
   UCUS98662, ms0:/seplugins/RAInGameLite/RAInGameLite.prx, on
   ```

   Не используй `always` или `vsh`, не включай одновременно старую пробу.
   Другие GAME-плагины на этот запуск остаются отключёнными.
5. Перезапусти PSP, запусти тот же LocoRoco (USA), пропусти вступительный
   ролик и начни первый уровень. Никакие комбинации кнопок не нужны.
6. Поиграй примерно 2–3 минуты, затем выйди HOME и подключи USB.
7. Передай `SEPLUGINS/RAInGameLite/lite.log` и сообщи, удалось ли начать
   уровень и продолжить играть. После теста отключи `RAInGameLite`.

`lite_finished` означает, что поток закончил работу; она заканчивается
также по запросу module_stop. Если игра снова выключается, дальнейшие запуски
этой версии не нужны: отключи новую запись и сохрани имеющийся `lite.log`.
Значения minimum_free/minimum_largest — минимум только в моменты опроса,
а не объём занятой памяти или гарантированный запас для игры. Нулевая свободная
память может означать предварительно выделенный heap игры и сама по себе
не доказывает ошибку. Сон/пробуждение в этом запуске не проверяется.

Историческая сборка 0.3: `scripts/build_ingame_lite.ps1`, закреплённый digest из
`dependencies.lock.json`, Docker/WSL без сети. В сборщике проверяется отсутствие
импортов отключённых функций. Общие ограниченный kernel-форматтер и logger
проверяются `make ingame-test`. В пакете нет ISO, старых логов или PLUGINS.TXT.
Сейчас этот сборщик создаёт 0.4-layout; архив 0.3 сохраняется отдельно.
