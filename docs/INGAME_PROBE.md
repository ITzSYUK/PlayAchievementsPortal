# Игровая диагностическая проба LocoRoco 0.2

**Версия 0.2 снята с дальнейшего тестирования:** на PSP владельца вызывает
выключение после вступительного ролика. С отключённым плагином игра работает.
Причина ещё не установлена; новый шаг — [облегчённая проба 0.3-lite](INGAME_LITE.md).
Инструкции ниже сохранены как история версии, повторять их сейчас не нужно.

Пакет собран для проверки на PSP-3000, 6.60 + ARK5. В версии 0.1 на PSP
подтверждены загрузка kernel PRX и обнаружение игры, но вызов регистрации
power callback в kernel вернул `0x80000004` и остановил пробу до загрузки
worker. В 0.2 обработчик перенесён в user worker; этот вариант ещё требует
проверки на PSP. Это диагностический плагин: он не входит в
аккаунт, не выполняет условия достижений, не отправляет unlock и не меняет
память игры. На экране нет меню или popup — результат записывается в файлы.

## Установка

1. Сохрани прежние диагностические логи. Распакуй `PSP_RA_InGameProbe_v0.2.zip`
   в корень Memory Stick. Появится `SEPLUGINS/RAInGameProbe` с тремя PRX,
   `cacert.crt`, `profile.txt` и справочным `reference.json`.
2. Для первого теста временно отключи другие GAME-плагины, включая старый
   PSPAchievementsNG, через менеджер плагинов ARK. Это позволит отличить
   влияние новой пробы. Сохранения и сам ISO не заменяй.
3. В существующий список ARK `ms0:/SEPLUGINS/PLUGINS.TXT` **добавь** одну
   строку из `INSTALL_ENTRY.txt` в архиве:

   ```text
   UCUS98662, ms0:/seplugins/RAInGameProbe/RAInGameProbe.prx, on
   ```

   Не заменяй весь список. Если плагины настроены в savedata-папке ARK, добавь
   строку в тот используемый список. Поддержку записи по ID показывает
   [документация ARK](https://github.com/PSP-Archive/ARK-4/wiki/Plugins);
   [исходники ARK5](https://github.com/PSP-Arkfive/ARK-5/blob/a9b74547c0d1785cc77981462cf095bd5a76434f/XMBControl/src/plugins.c)
   используют тот же формат записей. Можно также добавить kernel PRX через
   менеджер плагинов ARK с ограничением на ID `UCUS98662`.
   Для этой пробы нужна ровно одна запись: не добавляй `always`/`vsh`.
   Иначе при возврате в XMB проба может перезаписать игровой лог.
4. Включается только `RAInGameProbe.prx`. `RAInGameWorker.prx` и
   `RAProbeEntropy.prx` загрузит сама проба — отдельные записи для них не нужны.
5. `profile.txt` содержит `1`, проверенный ранее рабочий Wi-Fi-профиль. Если
   используешь другой, запиши только его номер 1–32 и перевод строки.
6. Безопасно отключи USB, включи переключатель Wi-Fi и запусти проверенный
   `LocoRoco (USA).iso`. Его ID из UMD_DATA — `UCUS-98662`, имя модуля `LocoRoco`,
   RA-хеш `199515744d49ef3620a5f9297c6116f9`. Эти значения получены из твоего ISO.

При обновлении с 0.1 замени оба файла `RAInGameProbe.prx` и
`RAInGameWorker.prx` из нового пакета; запись плагина остаётся той же.
Если в `profile.txt` был выбран другой номер, сохрани его. На карту не нужно
копировать справочные файлы и лицензии повторно ради этой замены.

## Один тестовый запуск

Наблюдение длится **5 минут с появления модуля игры**, затем завершается.
Начни с короткого обычного запуска без sleep и обмена/Game Sharing.

1. Дойди до первого уровня. Около 15 секунд оставайся в меню для исходного
   замера. Файлы `disc0:` хешируются автоматически в фоне небольшими блоками.
2. На первом уровне коротко нажми **L + R + SELECT** один раз: это метка
   `gameplay`. Поиграй около 30 секунд.
3. В безопасном месте коротко нажми **L + R + квадрат**: один HTTPS-запрос
   RetroAchievements без данных входа. Продолжай играть 30–60 секунд и оцени,
   появились ли заметные задержки, сбои звука или управления.
4. Поставь игру на обычную паузу кнопкой START. Затем коротко нажми
   **L + R + SELECT**: метка `paused-manual`. Оставь паузу на 15–20 секунд.
5. Сними паузу START, снова нажми **L + R + SELECT**: метка `resumed-manual`.
   Поиграй ещё 30 секунд. Комбинации только считываются, поэтому сама игра
   тоже видит эти кнопки; проба не перехватывает управление.
6. Дождись пяти минут от начала игры, затем выйди обычным HOME → выход в XMB.
   Подключи USB и скопируй **оба файла**:
   - `SEPLUGINS/RAInGameProbe/bootstrap.log`
   - `SEPLUGINS/RAInGameProbe/worker.log`

Перед новым запуском сохрани эти файлы: они перезаписываются. Вместе с ними
сообщи, как работали игра, звук и пауза. Если игра не запускается или появляется
зависание, после возврата в XMB отключи запись этой пробы через ARK; сохрани
имеющиеся логи. Не требуется обновлять прошивку или менять системные настройки.

## Как читать результат

- `DISC_HASH_MATCH`: байты PARAM.SFO + EBOOT.BIN через disc0 дали тот же RA-хеш,
  что официальный хешер ISO на компьютере. `DISC_HASH_MISMATCH`/`UNAVAILABLE`
  нужно передать как результат; подставлять справочный хеш нельзя. По каждому
  файлу записаны размер, MD5 и первые четыре байта magic, но не содержимое.
- `TLS_VERIFIED_IN_GAME`: TLS handshake, сертификат и заголовки HTTP прошли
  внутри игры. HTTP 422 от запроса без параметров допустим для этой проверки.
  Это не успешный запрос API аккаунта и не проверка полного тела ответа.
- `HTTPS_SKIPPED`: уже есть сетевые модули игры/другого плагина или отмена.
  Проба не переинициализирует и не выгружает чужой стек; пришли оба лога.
  Во время теста не переходи в Game Sharing: запуск сети самой игрой одновременно
  с этой пробой пока не проверен.
- `memory_segments`: успешно прочитанные фрагменты проверенных сегментов
  модуля. Каждый фрагмент — первые не более 64 байт; пишется только fingerprint.
  Это проверка доступа, а не адресов достижений или всей динамической памяти.
- `vblank` и `observed_buffer_changes`: разные замеры. Смены framebuffer
  наблюдаются опросом 5 мс и могут быть пропущены. Ни один показатель пока не
  объявлен игровым кадром; `frame_binding=UNPROVEN` ожидается.
- `worker_finished`/`observation_finished`, остаток TLS-выделений 0 и успешная
  очистка — критерии обычного завершения. Каждый лог ограничен 128 КиБ.
- В 0.2 `bootstrap.log` содержит `power_callback_owner=user_worker`.
  Создание/регистрация обработчика пишутся в `worker.log` до хеша и TLS.
  `POWER_CALLBACK_UNAVAILABLE` означает завершение без запуска этих операций.
  При ошибке освобождения callback worker не допускает unload своего кода.

Сеть и файлы обслуживаются отдельным user-потоком. На завершении/сне
устанавливается отмена; BIO/poll замечают её между вызовами. DNS имеет тайм-аут
7 секунд, но время системного вызова/криптографической операции не является
жёстко ограниченным. Если worker не завершился, модуль и его control block
удерживаются до выхода из игры вместо освобождения используемой памяти.
Sleep/resume выполняй отдельным следующим запуском только после обычного теста;
текущая проба при таком событии завершает сеанс и не продолжает TLS автоматически.
Обработчик сна принадлежит user-потоку и обслуживается в ожиданиях CB и между
операциями I/O через `sceKernelCheckCallback`; внутри callback только флаги,
без записи файлов или сетевых вызовов. Доставка события во время системного
вызова или криптографической операции может быть отложена до его завершения.

После теста отключи запись `RAInGameProbe` в ARK и верни прежние плагины, если
они нужны. Этот пакет не включает ISO или исходный офлайн-плагин.
