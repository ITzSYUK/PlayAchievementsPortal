## Подтверждено

На PSP ранее прошли HTTPS с проверкой сертификата, вход по токену, загрузка
101 достижения и очистка heap2MiB. Старый офлайн-движок проверяет .pach по
таймеру, показывает popup и пишет .dat; онлайн-зачёта RA у него нет.
История памяти важна: в официальном условии397986 есть Delta.

0.26 установила таблицу089B4ED0:0/0/08842D20/08841530/08841608/08842D90.
Обход08841788 вызывает метод+0x14 по08841800 при state+8==1 и(flags+0xA&7)==0.
Цикл08842CA0→08841788,08842CA8→08844440,08842CB0→08842CA0.
08844440 обрабатывает очередь событий, не ждёт кадра.
08841880 переключает бит0x02 для диапазона priority объектов.
088428B0 — VBlank subinterrupt, не доказательство игрового кадра.

0.29: временная замена только слота089B4EE4 обёрткой метода08842D90.
На PSP7161 вызов/120с, преимущественно60–61/с; оригинальный слот восстановлен,
очистка успешна. Владелец подтвердил START-паузу30с, нормальные управление и
продолжение. Объект0A7B2E8C вне разрешённого диапазона не читался;
FFFFFFFF в полях — отсутствие данных. Повторять0.26–0.29 не надо.

ВАЖНО: START-пауза внутри игры не равна остановке эмуляции/консоли.
Метод ввода не обязан прекращаться. Прежнее ожидание его остановки было
ошибкой. Не включать автоматический запрет кадров лишь по факту START-меню.

## PPSSPP и материалы

PPSSPP: VBlank/немедленная установка framebuffer→__DisplayFlip→needFlip
(dirty/fallback10VBlank/настройки)→DisplayFireFlip→HandleFlip→do_frame.
Это составное событие эмулятора, не каждый VBlank или SetFramebuf. Нельзя
«догонять» пропущенные кадры чтением текущей памяти. Код PPSSPP не копировался.

Читай docs/HTTPS_CLIENT.md (актуальная инструкция сверху),
docs/PPSSPP_FRAME_AUDIT.md, docs/INGAME_PROBE_STATUS.md, docs/ONLINE_AUDIT.md.
В старых разделах сохранены устаревшие инструкции — это история.
