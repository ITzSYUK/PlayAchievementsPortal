## Включение Encore

Сохранить `mode.txt = softcore`. Создать рядом `encore.txt`, содержимое:

```text
1
```

Перезапустить игру. Без файла или при `0` Encore выключен; в архиве по умолчанию
`0`. При ошибочном значении либо сочетании Encore=1 со spectator запуск
останавливается с -35421. Hardcore не включается. Пересборка для флага не нужна.

Используется `rc_client_set_encore_mode_enabled` закреплённого rcheevos 12.5.0.
Из ответа стартовой серверной сессии сохраняется ограниченный список исходных
открытий (до 128 ID). Private native callback can_submit_achievement_unlock
привязан к ABI commit 1433173220a7eaede6a9ed7a18e94117be1821e0:
он запрещает отправку для этих ID. До готовности снимка отправка через callback
запрещена; ошибка создания снимка прерывает загрузку. Подмены серверных ACK нет.

- Уже открытое достижение снова проверяется официальным движком. При выполнении
  появляется ENCORE — LOCAL REPLAY и звук, журнал ENCORE_REPLAY. Серверного
  award-запроса нет; счётчики earned/confirmed от повтора не увеличиваются.
- Достижение, которого не было в исходном серверном прогрессе, работает как
  обычное новое softcore-открытие и отправляется на сервер.
- Список сохраняет исходный SERVER CONFIRMED для уже открытого достижения.
  Повтор не превращает его в PENDING и не выдаётся за новое подтверждение.
- Encore разрешает повторное срабатывание один раз за загрузку набора.
  Он не изменяет сохранение игры и не отменяет официальную save protection.
  Для 397986 по-прежнему нужно своё сохранение с пройденным 1-1 и ещё не
  пройденным 1-2. Уже пройденный 1-2 сам по себе снова не сработает.

Карту, файл флага и аккаунт агент не меняет. Обычные новые достижения в
softcore+Encore по-прежнему реально начисляются при подтверждении сервера.

ELF metadata/heap/import/size guards пройдены. Heap и предельные размеры
модулей не увеличены. Архив `build/client-https/PSP_RA_HTTPS_v0.37.zip`.
